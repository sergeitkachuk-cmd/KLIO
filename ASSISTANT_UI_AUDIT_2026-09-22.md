# Проверка локального диалога assistant-ui — 22 сентября 2026

Область: рабочая копия `KLIO_dialogue_shell_v2`, ветка `codex/dialogue-shell-v2`,
черновой PR #1. Это проверка миграции интерфейса; не повторный аудит всего
сайта, оплаты, VK или внешних AI-провайдеров.

## Реализация

- Композиция ChatGPT Clone и настоящие React-примитивы assistant-ui собраны
  внутри приложения. Удалены пакет ChatKit, внешний loader, domain key,
  iframe и автоматическая смена оболочки. Облако assistant-ui не подключено.
- Поле ввода по центру пустого диалога, круглая отправка, компактный выбор
  режима через плюс, настройки под полем. Обычное общение — по умолчанию.
- Сохранены светлая и тёмно-синяя палитры, общие стили бизнеса, материалов,
  публикаций, переключатель бренда. Учитывать профиль — выключено по умолчанию.
  Перед отправкой с профилем завершается его сохранение.
- Сохранены все настройки текста/тем/изображений, логотип, импорт материала,
  подтверждение предложенного профиля и действия карточек.
- Результаты ведут к карточке в самой ленте. Превью картинок сохраняет
  пропорции, ограничено 420 × 360, скруглено; просмотр доступен по нажатию.
  Действия доступны и у карточки, и в просмотре изображения.
- История использует ту же БД и тот же ключ выбора диалога. Переименование,
  удаление с подтверждением и полная история с пагинацией сохранены.
- Новый store сохраняет черновики отдельно для каждого диалога. При
  потерянном ответе POST проверяет сохранённое сообщение и сохраняет requestId
  для явного повтора. Только сервер ведёт задания и списывает/возвращает лимиты.

## Найдено и исправлено при проверке

1. История могла пропускать записи с одинаковым updatedAt: курсор дополнен id.
2. Сохранённый материал после правки нельзя было обновить: учитывается снимок
   сохранённой версии, а не только наличие savedId.
3. Асинхронные действия карточки могли очищать другой текст в поле ввода:
   очищается только отправленный черновик. Новый текст, набранный во время
   запроса, сохраняется.
4. После перезагрузки неопределённого POST повтор мог получить новый requestId:
   id и состав запроса сохраняются; чтение принятого сообщения снимает ожидание.
5. Редактор карточки мог перезаписать изменения из другого окна: перед записью
   сравнивает исходную карточку; сервер дополнительно проверяет revision.
6. Перенос не должен терять общий CSS модулей: `dialogue.css` импортирован
   явно, без загрузки кода старой оболочки. Новые стили загружаются последними.
7. Создание бизнеса из предложения профиля переносит диалог в новое
   пространство: ключ выбора обновляется, старое личное пространство больше
   не пытается открыть уже перемещённый диалог.

## Границы проверки и приёмка

Браузерная автоматизация вернула пустой список браузеров; попытка открыть
in-app browser завершилась `Browser is not available: iab`. Поэтому реальные
скриншоты новой версии, Safari/Android, экранная клавиатура и отображение
при разных ширинах в этом сеансе не проверены. Happy DOM не измеряет реальную
раскладку CSS. Платные генерации, платежи и публикации клиентам не запускались.

На обновлённом стенде проверить без VPN:

1. Вход, новый диалог, ответ, обновление страницы и возврат к истории.
2. Телефон: открытие меню, клавиатура, длинный текст, прокрутка, закрытие popup.
3. Светлая/тёмная темы, материалы, публикации, смена бренда.
4. Темы с действиями; картинка с настройками и профилем; её превью и черновик
   публикации. Самостоятельной картинке не добавляется запрос как подпись.
5. Сбой сети во время отправки: черновик/история сохранены, повтор без
   дублирования принятого задания.

Маркер сборки: `X-Klio-UI-Release: 2026-09-22-assistant-ui-local-v1`.
Его наличие подтверждает версию сервера, но не полноценную приёмку интерфейса.
Переменная `KLIO_PREVIEW_SCHEMA=klio_preview_chatkit` сохраняется. Не менять
схему на public и не копировать рабочие таблицы для тестирования.
Слияние в main и выпуск клиентам — только после приёмки владельцем.
