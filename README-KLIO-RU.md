# КЛИО — последняя версия проекта

Архив подготовлен 2 августа 2026 года из актуальной опубликованной версии сайта КЛИО.

В состав входят:

- публичная презентационная страница;
- личный кабинет и переключение кабинетов брендов;
- генератор материалов;
- профиль бренда;
- модуль семантики;
- анализ конкурентов;
- контент-план с выборочной заменой тем;
- раздел «Материалы» с версиями результатов;
- редакторы КЛИО;
- раздельные лимиты материалов, исследований и AI-редактуры;
- адаптивный интерфейс для телефонов, планшетов и компьютеров;
- серверные API-маршруты и структура базы данных.

Мобильная версия не является отдельным сайтом: она реализована в тех же исходниках через адаптивные стили и компоненты. Поэтому все размеры экрана поддерживаются одной кодовой базой.

## Системные требования

- Node.js 22.13 или новее;
- npm;
- ключ OpenAI API для работы AI-функций.

## Локальный запуск

1. Откройте папку проекта в терминале.
2. Выполните `npm ci`.
3. Создайте файл `.env.local` на основе `.env.example`.
4. Укажите в нём `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL`.
5. Выполните `npm run dev`.

## Проверка и сборка

- `npm test` — сборка и функциональные проверки;
- `npm run lint` — проверка исходного кода;
- `npm run build` — производственная сборка.

## Развёртывание на Render

Проект работает на Render как **Web Service**, а не Static Site. В корне
репозитория находится `render.yaml`, который создаёт Node.js-сервис и базу
Render PostgreSQL, выполняет миграции и запускает Next.js.

При создании Blueprint укажите этот репозиторий и заполните секрет
`OPENAI_API_KEY`. Переменная `DATABASE_URL` подключается к созданной базе
автоматически.

Личный кабинет открыт для любого посетителя: регистрация и вход — по email
и паролю (`/signup`, `/login`), без общего пароля на весь сайт. Пароли
хранятся хешированными (scrypt), сессия — httpOnly-cookie, привязанная к
записи в таблице `sessions`. При открытии внутри ChatGPT как App по-прежнему
работает вход через заголовок ChatGPT — оба способа используют один и тот же
личный кабинет по email.

После регистрации доступ в кабинет заблокирован, пока не подтверждён email:
на адрес уходит письмо со ссылкой (действует 24 часа), без перехода по ней
войти нельзя — это отсекает ботов и опечатки в адресе. Письма отправляются
через [Resend](https://resend.com); нужен ключ `RESEND_API_KEY` (секрет,
задаётся в Render или `.env.local`). `RESEND_FROM_EMAIL` можно не менять —
по умолчанию используется тестовый адрес Resend `onboarding@resend.dev`,
который отправляет письма без подтверждения собственного домена; свой домен
можно подключить позже в панели Resend. Дополнительно `/api/auth/signup`,
`/login` и `/resend-verification` ограничены по частоте запросов с одного
IP (защита от перебора).

Для ручной настройки Web Service используйте:

- Build Command: `npm ci && npm run build`;
- Pre-Deploy Command: `npm run db:push`;
- Start Command: `npm start`;
- Health Check Path: `/api/ai-status`.
