# КЛИО — последняя версия проекта

Архив подготовлен 2 августа 2026 года из актуальной опубликованной версии сайта КЛИО.

В состав входят:

- публичная презентационная страница;
- личный кабинет и переключение кабинетов брендов;
- генератор материалов;
- профиль бренда;
- модуль семантики;
- анализ конкурентов;
- контент-план с выборочной заменой тем;
- раздел «Материалы» с версиями результатов;
- редакторы КЛИО;
- раздельные лимиты материалов, исследований и AI-редактуры;
- адаптивный интерфейс для телефонов, планшетов и компьютеров;
- серверные API-маршруты и структура базы данных.

Мобильная версия не является отдельным сайтом: она реализована в тех же исходниках через адаптивные стили и компоненты. Поэтому все размеры экрана поддерживаются одной кодовой базой.

## Системные требования

- Node.js 22.13 или новее;
- npm;
- ключ OpenAI API для работы AI-функций.

## Локальный запуск

1. Откройте папку проекта в терминале.
2. Выполните `npm ci`.
3. Создайте файл `.env.local` на основе `.env.example`.
4. Укажите в нём `OPENAI_API_KEY` и при необходимости `OPENAI_MODEL`.
5. Выполните `npm run dev`.

## Проверка и сборка

- `npm test` — сборка и функциональные проверки;
- `npm run lint` — проверка исходного кода;
- `npm run build` — производственная сборка.

## Важно

- Реальные API-ключи в архив не включены.
- Папки зависимостей, временные файлы и локальные служебные данные исключены.
- Файлы готовы для размещения в Git-репозитории.
- Исходное состояние сайта: версия 32, базовый коммит `553679d`.
- В пакет добавлена только одна техническая корректировка теста интерфейса; она не меняет работу или внешний вид сайта.
